# malekgontara.github.io

Personal portfolio site. One-page static site, no build step.

## Stack

- HTML, CSS, vanilla JS
- System fonts only — no external dependencies, no analytics

## Local preview

Just open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000   # then open http://localhost:8000
```

## Hosting

This repo is named `malekgontara.github.io`, which means GitHub Pages will serve it automatically from the `main` branch at https://malekgontara.github.io once it's pushed and Pages is enabled in the repo settings.
